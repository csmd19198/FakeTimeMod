# FakeTimeMod 设计文档

- 日期：2026-08-01
- 目标平台：Minecraft Java 1.20.1 · Forge 47.x · 纯客户端模组
- 兼容：Oculus（光影加载器）、机械动力（可选兼容）

## 1. 需求概述

在建筑服务器游玩时无法自由调整游戏内时间。本模组让**仅自己的客户端**显示与服务器不同的"虚假时间"，可自由调整并锁定，用于拍照和观赏（如欣赏夕阳）。服务器真实时间不受任何影响。

**需求明细：**

1. 暂停界面（ESC 菜单）底部显示控制面板，含：
   - 时间拖动条（以游戏刻 0~24000 为单位，像视频进度条）
   - 指针时钟（游戏刻换算为现实 24 小时制指针显示）
   - 「锁定时间」复选框
   - 「同步到服务器」按钮 + 服务器真实时间显示
2. 时间条未锁定时自动推进（跟随时间流动）；拖动后从新位置继续流动
3. 锁定后时间完全冻结
4. 客户端假时间一旦调整过，服务器时间再变化（如 `/time set`）也不影响客户端显示
5. Oculus/光影完全兼容（光影的太阳位置、光照色随假时间变化）
6. 服务器为晚上、客户端为白天时，刷怪、睡觉照常（不做处理——这是预期行为）
7. 钟表物品指针、第三方时钟（如机械动力布谷鸟钟）显示**服务器真实时间**
8. 无需快捷键

## 2. 架构

```
FakeTimeMod (Forge 1.20.1 纯客户端模组)
│
├── 主类         FakeTimeMod（@Mod 入口，注册事件、Mixin 配置）
│
├── 状态层       FakeTimeManager（单例）
│                · 状态机（见 §3）
│                · 客户端本地 tick 计数器（ClientTickEvent 自增，跨世界连续）
│                · 持久化（Forge 配置文件：模式、baseTicks、锁定状态）
│
├── 注入层       Mixin（见 §4）
│                · 让渲染管线读到假时间
│                · 让钟表/第三方时钟读到真时间
│
├── 界面层       PauseScreen 底部面板
│                · 时间条 + 指针时钟 + 锁定复选框 + 同步按钮 + 服务器时间
│
└── 持久层       forge 客户端配置文件（记住上次状态）
```

**核心原则：**
- 假时间只流向**渲染**（天空、太阳、月亮、光照颜色、Oculus 光影）
- 真时间保留给**逻辑**（刷怪、睡觉、钟表物品、第三方时钟——这些由服务器端判定或独立于渲染管线）
- 真实时间存储在**不被注入的位置**（`LevelData`），作为"基准值"

## 3. 时间状态机

```
真实时间 realT = 服务器同步的时间（存于 LevelData，不被注入）
客户端本地刻数 clientTicks = FakeTimeManager 自增计数器
```

| 状态 | 计算 | 说明 |
|---|---|---|
| FOLLOW（默认） | `fake = realT` | 跟随服务器，行为等同未安装模组 |
| INDEPENDENT（独立） | `fake = baseTicks + (clientTicks - anchorTicks)`，对 24000 取模 | 从用户拖到的时刻起，按客户端本地节奏独立流动，与服务器时间零耦合 |
| LOCKED（锁定） | `fake = lockedTicks` | 时间完全冻结 |

**状态转换（均由 GUI 操作触发）：**

| 操作 | 转换 |
|---|---|
| 拖动时间条（未锁定） | `baseTicks = 拖到时刻`，`anchorTicks = 当前 clientTicks` → INDEPENDENT |
| 拖动时间条（已锁定） | `lockedTicks = 拖到时刻` → 保持 LOCKED |
| 勾选「锁定」 | `lockedTicks = 当前 fake` → LOCKED |
| 取消「锁定」 | `baseTicks = lockedTicks`，重置 `anchorTicks` → INDEPENDENT |
| 点「同步到服务器」 | → FOLLOW（重新跟随服务器） |

**语义要点：**
- 拖动条范围 0~24000 游戏刻（MC 一天），显示 `fake % 24000`
- 未锁定状态时间条自动前进（fake 随 clientTicks 流动）
- **独立/锁定状态下服务器改时间，客户端时间纹丝不动**；FOLLOW 状态（用户尚未调整过）才跟随服务器
- 重进世界/换服务器：保持上次偏移与锁定状态（配置持久化），可配置改为进服重置

## 4. Mixin 注入点

| # | 目标 | 做法 | 效果 |
|---|---|---|---|
| 1 | `ClientLevel#getDayTime()` | 返回 `FakeTimeManager.compute(realT)` | 天空色、F3 显示、`isNight()`、光照暗度使用假时间 |
| 2 | `ClientLevel#getTimeOfDay(partialTick)` | 返回假时间换算 | 太阳/月亮角度、Oculus 光影世界时间 uniform |
| 3 | `ItemProperties` 静态块末尾 | 覆盖 CLOCK 的 `time` 属性函数，改读 `LevelData#getDayTime()` | 钟表物品指针转服务器真实时间 |
| 4 | 机械动力 `CuckooClockBlockEntity#clientTick`（`@Pseudo` 可选，`@Require(0)`） | 改读真实时间 | 第三方时钟显示服务器真实时间；未安装机械动力时静默跳过 |
| 5 | `ClientLevelData` | **不注入**（保留真实时间基准） | 同步按钮与面板显示真实服务器时间 |

**Oculus 兼容原理：** Oculus/Iris 计算光影世界时间 uniform 的唯一入口是 `ClientLevel#getTimeOfDay()` 与 `getDayTime()`（经太阳角、星亮度、天空暗度等派生）。注入 #1、#2 后光影自动使用假时间，无需额外适配。

**Mixin 优先度：** 适中（默认），与其它模组共存。

## 5. GUI 设计（暂停界面面板）

**位置：** ESC 暂停界面底部居中，半透明深色圆角面板，使用原生 MC 控件样式（SliderWidget、Checkbox、Button），不引入新纹理。

**面板布局（自上而下）：**

```
┌────────────────────────────────────────────┐
│  当前时间: 1000 刻  (7:00 AM)              │  ← 文本标签（实时刷新）
│                                            │
│  ●──────────────────────●─────────         │  ← 时间条 (0~24000刻)
│                                            │
│         [指针时钟]                          │  ← 表盘 + 时针分针
│                                            │
│  ☐ 锁定时间     [同步到服务器]              │  ← 复选框 + 按钮
│  服务器真实时间: 18000 刻 (12:00 AM)       │  ← 灰色小字，永远真实
└────────────────────────────────────────────┘
```

**组件：**

1. **时间条** — `SliderWidget` 子类，0~24000
   - 拖动实时生效（未锁定 → 立即进入 INDEPENDENT；锁定 → 立即改锁定值）
   - 未锁定时滑块位置随 fake 每 tick 推进
2. **指针时钟** — 原生钟表贴图放大为表盘 + 自绘时针/分针
   - 换算：0 刻 = 6:00 AM，1000 刻 = 7:00 AM（1 游戏刻 = 现实 0.864 秒，1000 刻 = 1 现实小时）
   - 时针角度 = (时 % 12 + 分/60) / 12 × 360°，分针角度 = 分/60 × 360°
3. **锁定复选框** — 原生 `Checkbox`
4. **同步按钮** — 原生 `Button`，按下 → FOLLOW
5. **服务器真实时间** — 灰色小字，始终显示 `LevelData` 真实时间

**技术实现：** Mixin 注入 `PauseScreen#init()`（TAIL）用 `addRenderableWidget` 注册面板组件；`render()` 绘制面板背景。面板置于屏幕底部留白处，若与「退出世界」等按钮重叠则微调位置（实现时实测）。

**交互规则：**
- 未锁定拖动 → 即时生效，关闭菜单后时间继续按新方向流动
- 锁定拖动 → 画面时间即时跳变（快速找夕阳）
- 面板状态持久化到配置文件，下次进游戏恢复

## 6. 边界情况与错误处理

| 场景 | 处理 |
|---|---|
| 服务器 `/time set`（独立/锁定状态） | 客户端时间纹丝不动（核心需求） |
| 服务器 `/time set`（FOLLOW 状态） | 跟随（尚未调整过；一拖条即独立） |
| 服务器重启 / 重进世界 | 保持上次偏移与锁定状态（配置可改进服重置） |
| 首次安装 / 无配置 | 默认 FOLLOW，行为等同未安装 |
| 未加入世界（主菜单） | 面板只在暂停界面出现，天然不显示 |
| 机械动力未安装 | `@Pseudo` 可选注入静默跳过 |
| 与其它注入 `getDayTime` 的模组共存 | Mixin 优先度适中，正常共存 |

**错误处理：**
- 注入方法内不做复杂计算；状态读取用 volatile 缓存，保证渲染性能
- 配置解析失败 → 回退默认值，不崩溃
- 面板渲染最小化每帧分配（预格式化字符串），避免 GC 卡顿

## 7. 测试

**单元测试（JUnit）：** `FakeTimeManager` 状态机
- 四种状态转换（FOLLOW → INDEPENDENT → LOCKED → INDEPENDENT → FOLLOW）
- 锁定/解锁、同步
- 跨天取模边界（23999 → 0、24000 循环）

**手动测试清单**（`runClient` + 本地局域网服务器）：
- [ ] 拖动时间条 → 天空/太阳立即变化
- [ ] 未锁定 → 时间条自动前进
- [ ] 锁定 → 时间冻结，太阳不动
- [ ] 同步按钮 → 恢复真实时间
- [ ] 服务器晚上、客户端白天 → 怪物正常生成、床正常可睡
- [ ] 服务器 `/time set` → 客户端已调整的时间不受影响
- [ ] 钟表物品指针 = 服务器时间
- [ ] 安装 Oculus + 光影 → 光影太阳位置、光照色随假时间变化
- [ ] F3 显示假时间
- [ ] 换服务器重进 → 状态保持

## 8. 构建

- Forge 1.20.1 (47.x) MDK
- Java 17（已确认本机已安装）
- Gradle wrapper（MDK 自带）
- 依赖：`forge` 与 `mixin`（Forge 1.20.1 自带 Mixin 支持）
- 可选兼容：机械动力（仅运行时检测，不硬依赖）

## 9. 明确不做的事

- 不改变服务器时间（纯客户端，不发送任何时间修改包）
- 不处理"白天刷怪/睡觉"（服务器判定，保持原样）
- 不加快捷键
- 不做除机械动力布谷鸟钟之外的第三方模组适配（后续按需添加）
